# Uber: Designing the Autonomous Transition

A responsive MOR 530 case-study webpage addressing Tesla FSD incentives, third-party Level 4 integration, human-driver marketplace effects, and product strategy.

## Contents

- Research and references with evidence limitations
- Strategic alternatives and recommended hybrid approach
- Driver incentives, rider experience, and partner selection
- Marketplace distributional effects and unit economics
- Interactive incremental-demand scenario (illustrative, not a forecast)
- Metrics, experimental design, and phased rollout criteria
- Rotating 3D car explorer with ten indexed case topics, reading dialogs, drag controls, and reduced-motion support
- Original Uber-inspired route illustration and interactive rider/driver concept mockups
- Mobile layout and Print / Save PDF support

## Deploy on Vercel

1. Import this GitHub repository into a new Vercel project.
2. Use **Other** as the framework preset and keep the repository root as the Root Directory.
3. The included `vercel.json` configures `public` as the Output Directory and disables the build step.
4. Deploy. No environment variables, dependencies, or backend are needed.

Vercel documentation: https://vercel.com/docs/builds/configure-a-build

## View or edit locally

Open `public/index.html` directly in a browser. Keep `explorer.css` and `explorer.js` alongside it; these provide the rotating car and topic dialogs. The site uses no external JavaScript libraries or downloaded 3D models.

The page cites Stanford GSB case SI-187 and external research. The original course PDF is not included.
